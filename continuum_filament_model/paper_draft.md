# 要旨（初稿）

本研究では、散逸性基板上で成長するひも状構造が、伸長弾性、曲げ弾性、基板抵抗、自己接触の競合によって座屈・折りたたみ・空間充填へ遷移する条件を調べる。対象として、硬い寒天上で成長し、逐次的な折りたたみを示す *Bacillus subtilis* のフィラメントを念頭に置く。

まず、質点の慣性を無視した過減衰連続モデルを、参照長の成長、伸長エネルギー、曲げエネルギー、接触則から構成する。続いて、単純な緩和、数値収束、成長による座屈、自己接触のベンチマークを実施する。実験画像から抽出した中心線と、全長、曲率、折りたたみ間隔、接触長、慣性半径などを比較し、物理パラメータの同定可能性を検討する。

さらに、既存の三角格子上の成長モデルを、連続モデルと同一視せず、自己回避と局所曲げバイアスを保持した粗視化系として位置づける。両者の共通観測量を比較することで、物理パラメータと形態統計の関係を調べる。

本稿の現段階では、定量的な実験再現や普遍性の帰属は主張しない。物理仮定、検証方法、データ契約、粗視化対応を明示し、再現可能な研究基盤を構築することを目的とする。

# 1. 背景

## 1.1 成長するひも状構造

ひも状の生物・物質が平面上で成長すると、成長に伴う長さの増加だけでなく、曲げ、圧縮、基板抵抗、自己接触が形態を決める。単純な直線成長は、成長が力学的緩和より速い場合に座屈し、折りたたみや接触を伴う構造へ移行する可能性がある。

本リポジトリの研究原稿では、2次元平面上の質点列をばねと曲げ弾性で結び、自然長を増加させるモデルが検討されている（`source/01_growing_natural_length_model.tex`）。一方、自己排他性を安定して扱うため、三角格子上の成長モデルも発展してきた（`source/03_triangular_lattice.tex`）。

## 1.2 実験系との接続

Honda、Wakita、Katoriは、硬い寒天・高栄養条件下で、細胞分離の失敗によりフィラメント状に成長する *Bacillus subtilis* と、逐次的な折りたたみを報告している。

- [Self-Elongation with Sequential Folding of a Filament of Bacterial Cells](https://journals.jps.jp/doi/abs/10.7566/JPSJ.84.114002)

本研究では、実験画像の見た目を直接再現することではなく、中心線の時系列から得られる成長率、曲率、接触、形態統計をモデルの予測と比較する。

# 2. 研究目的

本研究の主目的は、次の問いに答えることである。

> 成長率、伸長剛性、曲げ剛性、基板抵抗、自己接触は、フィラメントの座屈・折りたたみ・空間充填の遷移をどのように決めるか。

副目的は次のとおりである。

1. 成長する弾性フィラメントの最小連続モデルを構築する。
2. エネルギー、散逸、数値収束を検証する。
3. 実験中心線データから物理パラメータを校正する。
4. 校正に使わない形態量でモデルを評価する。
5. 三角格子モデルを、自己回避・確率的成長の粗視化系として比較する。

# 3. モデル

## 3.1 状態変数

フィラメントを、2次元の開曲線として節点列

```text
r_0, r_1, ..., r_{N-1}
```

で表す。各線分には、現在の幾何学的長さとは別に、無応力状態の参照長 `a_i` を持たせる。

この区別により、成長を「現在の座標を直接伸ばす操作」ではなく、「参照配置の変化」として扱う。

## 3.2 エネルギー

初期モデルのエネルギーは、伸長、曲げ、接触の和とする。

```math
E = E_s + E_b + E_c
```

伸長エネルギーは、連続体の軸剛性 `EA` を線分へ離散化して

```math
E_s = Σ_i [ EA / (2a_i) ] (l_i-a_i)^2
```

とする。

曲げエネルギーは、節点の二階差分 `q_i=r_{i-1}-2r_i+r_{i+1}` を用いて

```math
E_b = Σ_i [ EI / (2a_ref^3) ] |q_i|^2
```

とする。これは初期の離散化であり、大きな曲率・大きな伸長に対する妥当性は検証課題である。

自己接触は、初期版では非隣接節点間の軟接触として

```math
E_c = Σ_{i,j} (k_c/2)[d_c-|r_i-r_j|]_+^2
```

とする。最終的な実験比較では、節点間ではなく線分間の距離、摩擦、接着を扱う必要がある。

## 3.3 散逸と時間発展

硬い基板上の低速な成長を第一近似として、慣性を無視した過減衰方程式を採用する。

```math
Γ_i v_i = -∂E/∂r_i
```

ここで `Γ_i` は参照長に比例する基板ドラッグである。初期実装では陽的Euler法とステップ棄却を使う。

成長なし・外力なしの場合には、十分小さい刻み幅で

```math
dE/dt <= 0
```

となることを検証する。成長中は参照長の変化がエネルギーを注入するため、全エネルギーの単調減少は期待しない。

## 3.4 成長と再メッシュ

参照長は初期版では一様な相対成長率 `g` により、

```math
a_i(t+dt)=a_i(t)exp(g dt)
```

と更新する。

`a_i` が上限を超えた場合は中点で分割する。ただし、この分割は物理的な細胞追加ではなく、数値再メッシュである。合計参照長は保存し、軸剛性・曲げ剛性を分割時に恣意的に変更しない。

# 4. 実装

新しい実装は `continuum_filament_model/src/growing_filament/` に置く。既存の
`growing_natural_length_model/`、`constant_length_model/`、`triangular_lattice/` は変更しない。

主なファイルは次のとおりである。

- `model.py`：状態、パラメータ、エネルギー、力、成長、時間発展
- `observables.py`：全長、慣性半径、曲率などの観測量
- `io.py`：可変節点数の軌跡をprimitive arrayで保存
- `run_smoke.py`：非GUIの最小実行
- `tests/test_model.py`：初期の不変条件・緩和テスト

初期実装は研究結果を生成する完成版ではなく、物理仕様と検証を分離するためのプロトタイプである。

# 5. 検証方法

## 5.1 数値検証

- 直線・無伸長状態でエネルギーと力がゼロになること。
- 平行移動・回転に対してエネルギーが不変であること。
- 解析勾配と有限差分勾配が一致すること。
- 成長なしの緩和でエネルギーが非増加であること。
- `dt` と再メッシュ閾値を変えたときに観測量が収束すること。
- 非隣接線分の交差が検出され、ステップが棄却されること。

## 5.2 力学的検証

### 直線成長

端点固定の直線フィラメントを成長させ、軸方向の応力、参照長、現在長、座屈開始条件を測定する。

### 曲げ緩和

折れた初期形状を成長なしで緩和させ、曲率とエネルギーの時間発展を調べる。

### 座屈

初期ゆらぎ、成長率、曲げ剛性、端部条件を変え、座屈開始と波長を測定する。

### 接触

U字・S字形状を使い、接触後に交差せず折りたたまれるかを確認する。接触したまま成長する実験結果を再現するには、反発だけでなく接着や摩擦が必要になる可能性がある。

# 6. 実験データとの比較

## 6.1 必要な入力

実験の中心線は、少なくとも次の形式に整理する。

```text
time, filament_id, point_id, x, y, quality
```

併せて、ピクセル長、撮影間隔、温度、寒天条件、栄養条件、セグメンテーション方法、欠損の扱いを保存する。

## 6.2 校正する量

- `L(t)` から成長率
- 単純な曲げ緩和から `EI/zeta`
- 伸長応答から `EA`
- 接触形態から径・接触パラメータ

## 6.3 独立に評価する量

- 曲率分布
- 折りたたみ間隔
- 接触長
- 端点間距離
- 慣性半径
- roughness
- フラクタル指標の時間発展

校正と評価に同じ観測量を使わない。画像の見た目だけでは、実験整合と判定しない。

# 7. 三角格子モデルの粗視化

## 7.1 位置づけ

既存の `triangular_lattice/` は、連続モデルの数値解そのものではなく、次の特徴を持つ粗視化系として扱う。

- 6方向の離散的な接線
- 占有による自己回避
- 局所曲げバイアス
- 離散的な成長イベント

既存の `beta` は現時点では物理温度や曲げ剛性ではない。連続モデルとの対応は、接線相関、実効持続長、曲率分布を介して調べる。

## 7.2 比較する観測量

- 輪郭長に対する端点間距離
- 接線相関
- 慣性半径
- 曲率・折れ角分布
- 接触・自己回避率
- roughness
- 成長量に対する形態変化

SAW、kinetic growth walk、Edenは対照系として利用する。平衡SAW、Eden、連続モデル、三角格子成長モデルを、同じモデルだと主張しない。

# 9. 限界と今後の課題

現段階では、次を主張しない。

- 実験の定量的再現
- 実験系のパラメータ同定の完了
- 三角格子モデルと連続モデルの力学的同値性
- `beta` と物理温度・曲げ剛性の一意な対応
- KPZ、WLC、アクティブマターなどの普遍性クラスへの帰属

今後は、まずPhase 0〜2の数値・力学検証を完了し、その後に実験中心線データを用いた校正と予測評価へ進む。
