# モデル仕様（初期版）

## 状態

開曲線を `N` 個の節点で表す。

```text
r = (r_0, ..., r_{N-1}),  r_i ∈ R^2
```

各線分の参照長・無応力長を

```text
a_i > 0, i = 0, ..., N-2
```

とする。現在の幾何学的長さは

```text
l_i = |r_{i+1} - r_i|
```

であり、`a_i` と一般には一致しない。

現段階では速度を状態として保存しない。基板上の過減衰方程式から毎ステップ求める。

## エネルギー

### 伸長

離散化の代表長を `a_i` とし、連続体の軸剛性 `EA` から線分剛性を導く。

```math
E_s = Σ_i [ EA / (2 a_i) ] (l_i - a_i)^2
```

この仕様では、成長しても `EA` は材料パラメータとして保持し、線分剛性は参照長に応じて変化する。

### 曲げ

内点における二階差分

```text
q_i = r_{i-1} - 2 r_i + r_{i+1}
```

を用い、固定の基準長 `a_ref` に対して

```math
E_b = Σ_i [ EI / (2 a_ref^3) ] |q_i|^2
```

とする。これは、小さい曲率で曲げエネルギーを近似する初期仕様である。大きな角度・大きな伸長での妥当性は未検証。

### 接触

初期版は非隣接節点間の軟接触を実装する。

```math
E_c = Σ_{i,j} (k_c / 2) [d_c - |r_i-r_j|]_+^2
```

ここで `d_c` は排除距離、`[x]_+=max(x,0)` である。線分間接触ではないため、最終的な実験比較へ使う前に線分間の距離・接触・摩擦へ拡張する必要がある。

## 散逸

節点に割り当てる参照長重みを

```text
w_0 = a_0 / 2
w_i = (a_{i-1} + a_i) / 2
w_{N-1} = a_{N-2} / 2
```

とし、ドラッグを

```text
Γ_i = zeta * w_i * I
```

とする。力学方程式は

```math
Γ_i v_i = -∂(E_s+E_b+E_c)/∂r_i
```

である。

固定端の場合は、対応する節点を初期位置へ戻し、速度を0にする。

## 成長

初期版は空間一様な相対成長率 `g` を使う。

```math
a_i(t+dt) = a_i(t) exp(g dt)
```

空間依存成長や先端成長は、実験データの成長分布を確認してから追加する。

成長はエネルギーを注入する。従って、成長中に全エネルギーが単調減少することは受入条件ではない。成長なしの場合の散逸・エネルギー減少を別に検証する。

## 再メッシュ

参照長が `a_max` を超えた線分を中点で分割し、分割後の各子線分も再確認する。
必要なら再帰的に分割し、再メッシュ後のすべての線分の参照長を `a_max` 以下にする。

```text
r_new = (r_i + r_{i+1}) / 2
a_left = a_right = a_old / 2
EA, EI は変更しない
```

これは物理的成長ではなく数値再メッシュである。合計参照長と端点は保存する。

初期版では、線分を結合する逆再メッシュは実装しない。再メッシュ規則が観測量へ与える影響を評価してから追加する。

## 時間積分

初期版は陽的Euler法を使う。

```text
F = -grad(E)
v = Γ^{-1} F
r_trial = r + dt v
```

以下の場合は試行を棄却して `dt` を半分にする。

- 非有限値が出た。
- 1ステップの移動量が大きすぎる。
- 非隣接線分が交差した。
- `dt_min` を下回った。

陽的Euler法を最終手法と決めたわけではない。単体テストと収束試験を通過した後、半陰解法を比較する。

## 境界条件

初期版は開曲線のみを対象とし、端点ごとに次を設定する。

- `free`：力に従って移動
- `fixed`：初期位置に固定

ピン端、外部押し込み、周期境界、閉曲線は初期版の対象外である。

## 出力

状態履歴には少なくとも次を保存する。

- `positions`
- `rest_lengths`
- `time`
- `step`
- `parameters`
- `schema_version`
- `git_revision`（実験実行時に付与）
- `seed`（確率過程を追加した場合）

可変節点数の履歴をobject配列へ保存せず、flat arrayとoffset配列へ分ける。初期版の `io.py` はこの形式を採用する。
