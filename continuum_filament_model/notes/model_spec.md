# モデル仕様（初期版）

## 状態

開曲線を `N` 個の節点で表す。

```text
r = (r_0, ..., r_{N-1}),  r_i ∈ R^2
```

各線分の参照長・無応力長を

```text
a_i > 0, i = 0, ..., N-2
```

とする。現在の幾何学的長さは

```text
l_i = |r_{i+1} - r_i|
```

であり、`a_i` と一般には一致しない。

現段階では速度を状態として保存しない。基板上の過減衰方程式から毎ステップ求める。

## エネルギー

### 伸長

離散化の代表長を `a_i` とし、連続体の軸剛性 `EA` から線分剛性を導く。

```math
E_s = Σ_i [ EA / (2 a_i) ] (l_i - a_i)^2
```

この仕様では、成長しても `EA` は材料パラメータとして保持し、線分剛性は参照長に応じて変化する。

### 曲げ

各線分の幾何学的単位接線と、内点の参照長による双対セルを定義する。

```text
t_i = (r_{i+1} - r_i) / l_i
h_i = (a_{i-1} + a_i) / 2
Δt_i = t_i - t_{i-1}
```

曲げエネルギーは

```math
E_b = Σ_i [ EI / (2 h_i) ] |Δt_i|^2
```

とする。これは `EI/2 ∫ κ^2 ds` の局所参照長離散化である。`h_i`
を固定の `a_ref` に置き換えた旧式では、同じ折れ線の各線分を中点分割
すると二階差分が半分になり、曲げエネルギーが `1/4` になるため採用しない。
単位接線を使うことで、伸長した直線にも曲げエネルギーを人工的に付加しない。

力はこのエネルギーの解析的な負の勾配とする。線分 `i` の
`P_i = I - t_i t_i^T` を用いると、各 `Δt_i` の寄与は

```text
F_{i-1} -= (EI / h_i) P_{i-1} Δt_i / l_{i-1}
F_i     += (EI / h_i) (P_{i-1} Δt_i / l_{i-1}
                       + P_i Δt_i / l_i)
F_{i+1} -= (EI / h_i) P_i Δt_i / l_i
```

である。有限差分の負のエネルギー勾配テストを、この式の回帰条件とする。
大きな角度・大きな伸長での連続体近似の妥当性は未検証。

#### 折れ線に対する離散化契約

中点再メッシュは、線分の幾何学的中点を追加し、参照長を等分する。したがって
端点、総参照長、折れ線の幾何学的輪郭長は保存量である。節点平均の観測量は
保存量ではないため、再メッシュ非依存の形状比較には弧長積分を使う。

角点を持つ固定折れ線では、`Δt_i` は同じでも `h_i` は角点の両側の分割に
よって半分になる。このため角点の曲げエネルギーと節点力は一般に変化する。
これは折れ線の曲率が角点で特異（連続体の `∫κ^2 ds` が有限でない）であることに
対応しており、角点についてのメッシュ独立性は受入条件にしない。角点の物理的な
丸みを表す場合は、丸みを解像した形状を各解像度で弧長サンプルして比較する。
滑らかな形状では `Δt_i = O(h_i)` なので、曲げエネルギーは解像度 refinement
に対して収束する。小規模ベンチマークでは、角点を除いた内部力残差、曲げ
エネルギー、弧長重み慣性半径を比較する。

### 接触

非局所線分対 `(i,j)` の最近接点を `x(s)`、`y(u)`、距離を `d`、排除径を `D` とする。
既存の `geometry.py` の `nonlocal_segment_contacts()` が返す `s,u ∈ [0,1]` と法線
`n=(x-y)/d`（`d>0`）を使い、摩擦なしの有限径 penalty を計算する。

```math
δ_{ij} = [D-d]_+ = max(0,D-d)
E_{c,ij} = (k_c/2) δ_{ij}^2
f_{ij} = k_c δ_{ij} n
```

`f_ij` は線分 `i` へ加え、線分 `j` へ `-f_ij` を加える。4端点には最近接パラメータによる
双線形形状関数で scatter する。

```text
F_i     += (1-s) f_ij       F_{i+1} += s f_ij
F_j     -= (1-u) f_ij       F_{j+1} -= u f_ij
```

この線分接触を標準の非局所接触応答として `forces()` と `energy_components()` に含める。
過去のパラメータ・3節点 fixture との互換性のため、既存の非隣接節点 penalty も同じ
`contact_stiffness` で加算する。節点・線分が同時に閾値内となる形状では両方の項が寄与する。
定式化、`d=0` で法線を選ばない境界、U字 fixture、有限差分・作用反作用・剛体変換の検証は
`notes/segment_penalty_contact.md` に記録する。

`growing_filament.geometry` は引き続き、最近接距離・最近接点・パラメータ・有限径の
`gap=d-D`・`penetration=max(0,D-d)`・feature・normal status を方式非依存に提供する。
初期形状に非隣接線分の交差がある場合は、`reject_crossing` の設定にかかわらずモデル生成を拒否する。
`d=0` の交差・共線重なりでは法線が一意でないため、接触エネルギーは定義するが任意の反発方向は
生成しない。有限の時間刻みでの非貫入保証、摩擦・接着、動的CCDは未実装であり、`diameter` と
最近接距離は実験妥当性を意味しない。

## 散逸

節点に割り当てる参照長重みを

```text
w_0 = a_0 / 2
w_i = (a_{i-1} + a_i) / 2
w_{N-1} = a_{N-2} / 2
```

とし、ドラッグを

```text
Γ_i = zeta * w_i * I
```

とする。力学方程式は

```math
Γ_i v_i = -∂(E_s+E_b+E_c)/∂r_i
```

である。

固定端の場合は、対応する節点を初期位置へ戻し、速度を0にする。

イベント記録には要求 `dt`、各試行 `dt`、受理 `dt`、時刻・ステップ、状態の有限性・節点数・最小線分長・
最小非局所距離・最大移動量、試行前後のエネルギー要約を含める。接触イベントは診断であり、接触力を
線分へ追加するものではない。

## 成長

初期版は空間一様な相対成長率 `g` を使う。

```math
a_i(t+dt) = a_i(t) exp(g dt)
```

空間依存成長や先端成長は、実験データの成長分布を確認してから追加する。

成長はエネルギーを注入する。従って、成長中に全エネルギーが単調減少することは受入条件ではない。成長なしの場合の散逸・エネルギー減少を別に検証する。

## 再メッシュ

参照長が `a_max` を超えた線分を中点で分割し、分割後の各子線分も再確認する。
必要なら再帰的に分割し、再メッシュ後のすべての線分の参照長を `a_max` 以下にする。

```text
r_new = (r_i + r_{i+1}) / 2
a_left = a_right = a_old / 2
EA, EI は変更しない
```

これは物理的成長ではなく数値再メッシュである。合計参照長と端点は保存する。
幾何学的中点を使うため、分割前後の各子線分の長さの和も元の線分長に
丸め誤差内で一致し、総輪郭長も保存する。

初期版では、線分を結合する逆再メッシュは実装しない。再メッシュ規則が観測量へ与える影響を評価してから追加する。

## 時間積分

初期版は固定メッシュの陽的Euler法を使う。

```text
F = -grad(E)
v = Γ^{-1} F
grown = a exp(g dt)
(r_trial, a_trial) = remesh(r, grown, a_max)
r_trial = r_trial + dt v
```

`ModelParameters.validate()` は計算開始前に、物理・数値パラメータのすべての数値入力が有限値であることを確認する。状態の非有限値、1ステップの移動量超過、非隣接線分の交差は試行を棄却する。
各試行の端点を線形に補間した `t∈[0,1]` の軌跡について、向き判定の二次多項式の根で区間を分割し、
終状態が非交差でも中間で起きる swept crossing を検出する。初期交差、接触、交差棄却、非有限値、
移動量超過は、`events` の構造化記録で別の `reason` として保持する。

成長率 `g=0` の試行では、現在の全エネルギーを `E_old`、試行後の全エネルギーを
`E_trial` として、次の条件を満たす場合だけ受理する。

```text
E_trial <= E_old + energy_tolerance * max(1, |E_old|)
```

不安定な試行を棄却している間は、状態、参照長、時刻、ステップ番号を変更せず、`dt` を半分にして再試行する。`dt_min` を下回るまで受理できなければ、最後の棄却理由を含むエラーにする。受理した刻み幅と棄却理由は、小規模診断用に `accepted_dts`、`rejected_dts`、`rejection_reasons` へ記録する。これはGate 3の一般イベントschemaではない。

成長率 `g>0` では参照長が変化し、成長がエネルギーを注入し得る。このため、成長ありの試行に上記の単調非増加条件を適用しない。成長中のエネルギーを単純に単調減少と解釈してはならない。

陽的Euler法を最終手法と決めたわけではない。単体テストと収束試験を通過した後、半陰解法を比較する。

### 固定メッシュの製造解

再メッシュの影響を除いて時間積分だけを検証するため、3節点を一直線に配置し、両端を固定し、成長・接触を無効にする。単位参照長・単位ドラッグ・`EA=2` とし、中央節点の初期座標を `x(0)=1.25`、平衡座標を `x*=1` とする。このとき中央節点は

```math
dx/dt = -4(x-1), \qquad x(t)=1+0.25\exp(-4t)
```

を満たす。`a_max=2` とするため、`a_i=1` の固定メッシュから再メッシュは発生しない。`dt=0.02, 0.01, 0.005` で `t=0.2` まで積分し、最終中央座標の解析解誤差を比較する。誤差の観測次数が1となることを、陽的Eulerの一次収束の受入条件とする。

固定メッシュ診断 `run_fixed_mesh_diagnostic()` は、エネルギー時系列、時刻、節点数、受理した `dt`、棄却した `dt` と理由を返す。候補刻み `0.01` と半分の `0.005` について、全受理ステップのエネルギーが有限かつ許容誤差内で非増加であることを確認する。

## 境界条件

初期版は開曲線のみを対象とし、端点ごとに次を設定する。

- `free`：力に従って移動
- `fixed`：初期位置に固定

ピン端、外部押し込み、周期境界、閉曲線は初期版の対象外である。

## 出力

状態履歴には少なくとも次を保存する。

- `positions`
- `rest_lengths`
- `time`
- `step`
- `parameters`
- `schema_version`
- `git_revision`（実験実行時に付与）
- `seed`（確率過程を追加した場合）

可変節点数の履歴をobject配列へ保存せず、flat arrayとoffset配列へ分ける。初期版の `io.py` はこの形式を採用する。
