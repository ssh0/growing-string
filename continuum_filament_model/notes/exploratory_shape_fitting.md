# `gray5` 実観察中心線への探索的形状フィッティング

## 目的と位置づけ

`benchmarks/exploratory_shape_fitting.py` は、抽出済みの
`results/presentation_data/video_gray5/centerline.csv` に対して、連続体フィラメント
モデルの形状を高解像度で重ね合わせるための探索スクリプトである。節点数を
`n_nodes=25`（CLIで25〜35程度に変更可能）へ増やし、`G_b`、`chi`、モデル上の
成長時間を grid 探索する。

これは物性値の独立な同定や動画追跡の妥当性検証ではない。最新の代表フレームを
滑らかな初期形状としてモデルへ与えるため、実観察に対する**探索的な形状整合性の
確認**である。`centerline.csv` の `censor` と `quality_flags` は捨てずにサマリーと
ノートブックへ引き継ぐ。censor付きの低い残差は、単一フィラメントの追跡成功や
モデルの物理的妥当性を意味しない。

## 入力と代表フレーム

既定では、次の2フレームを最近傍選択する。

- `t=1 s`: 変化を見るための代表フレーム
- `t=3 s`: 形状fitのtarget。既定の探索では、この最新代表フレームを滑らかなモデル初期形状のseedにも使う

`--target-times` と `--filament-id` で変更できる。指定時刻から既定の許容差
`0.51 s` を超える場合は、観察を補完せず失敗する。各中心線は弧長で再サンプルし、
pixelの階段状ノイズを5点カーネルで2回平滑化してから、始点を原点、始点から終点の
弦を+x方向、輪郭長を `model_length=2` とする座標へ写像する。この処理は初期条件の
数値解像度を整えるためで、物理校正ではない。

## 力学モデルと探索グリッド

候補ごとに `OverdampedGrowingFilament` を実行する。数値上は

\[
  EA=1,\quad \zeta=1,\quad EI=\chi EA L^2,
  \qquad g=G_b/\tau_b,
  \qquad \tau_b=\frac{\zeta L^4}{EI\pi^4}
\]

と置く。したがって `chi` と `G_b` の定義はモデルの無次元量と一致する。端点は
固定し、接触なし・中心線交差棄却ありとする。`EA=1` は同じ無次元比を保つための
数値スケールであり、観察動画の物理単位への校正値ではない。

既定の粗探索は次の通り。

| 量 | 候補 |
| --- | --- |
| `n_nodes` | 25 |
| `G_b` | 0.2, 0.775, 1.35, 1.925, 2.5 |
| `chi` | 0.0001, 0.0003, 0.0006, 0.001 |
| モデル成長時間 | 0.02, 0.05 |
| 時間刻み | 0.01 |

粗探索の最良候補の周囲で、`G_b` と成長時間は線形3点、`chi` は対数3点へ
refineする。`--no-refine` を指定すると粗探索だけになる。複数フレームを選んだ
場合、target以外のフレームに対する正規化損失の中央値を候補スコアとする。

## 特徴量の選定

摂動、熱揺らぎ、微小流動、初期不整がある動画では、全ピクセル座標の一致を目的に
すると、物理的な形状が近くても局所的な揺らぎで損失が大きくなる。そこで、形状を
次の無次元特徴量ベクトル
`Phi=(Amax/chord, L/chord, mean(|kappa|)L, RMS(kappa)L, max(|kappa|)L, mode1, mode2/mode1, mode3/mode1)`
へ写像してから、重み付き二乗残差を計算する。

- `Amax/chord` は端点間の弦に対するたわみ比で、平行移動・一様スケールに不変。
- `L/chord` はたるみ・伸長収縮の幾何比で、点密度の違いに依存しにくい。
- 曲率の平均・RMS・最大値に `L` を掛けることで、pixel単位の曲率を無次元化し、
  線長の異なるフレームを比較する。
- `mode1`、`mode2/mode1`、`mode3/mode1` は弧長正規化した横方向の低次モードで、
  大域的な座屈形状と局所的な揺らぎを分けて見る。
- 観察時刻に対する `d(log L)/dt` は、形状だけではない成長の時間情報として、
  特徴量損失の二次項に加える。

候補スコアは、形状特徴量の重み付き二乗平均に、選択フレーム間の成長率残差を加えた
ものとする。Fréchet距離と曲率RMSEは、特徴量だけでは見落とす中心線の順序付き形状を
監査するために併記する。したがって、最適化の主目的を座標の一点一致から特徴量の
一致へ移しつつ、図では座標重ね合わせも確認できる。

## 残差と登録

候補モデルは、比較対象フレームに対して次の一つの相似変換だけで登録する。

1. 始点を観察の始点へ移動する。
2. 始点から終点の向きを観察の弦方向へ回転する。
3. モデルと観察の輪郭長の比で一様スケールする。

局所的なワープ、点ごとの対応付け、向きの反転による形状の改変はしない。forwardと
reverseを比較し、損失が小さい向きを採用する。

- **離散Fréchet距離**: 弧長再サンプルした中心線間のpixel距離。輪郭に沿った対応の
  順序を保った最大最小距離である。
- **曲率プロファイルRMSE**: 同じく弧長再サンプルした符号付き離散曲率の
  `pixel^-1` RMSE。
- **特徴量損失**: 各特徴量の宣言済みスケールで標準化した二乗残差の平均。
- **探索スコア**: 特徴量損失の中央値 + 観察時間に対する成長率残差の二乗 +
  `50 * Frechet / observed_contour_length`。特徴量を主軸にしつつ、目視で中心線を
  外す候補を選ばないための順序付き形状項を残す。
- **曲率監査指標**: `Frechet / observed_contour_length + curvature_RMSE * observed_contour_length`

出力の `improvement` は、最良モデルと同じ登録手順で計算した直線中心線 baseline
との差である。holdout評価、誤差モデル、pixel-to-physical calibrationを含まない。

## 実行と出力

```bash
PYTHONPATH=continuum_filament_model/src \
python continuum_filament_model/benchmarks/exploratory_shape_fitting.py \
  --output continuum_filament_model/results/presentation_data/exploratory_fitting
```

出力先には次を保存する。

- `best_fit_comparison.png`: target seedとtarget出力の重ね合わせ、無次元特徴量の観察／モデル比較、
  特徴量の時間発展、曲率プロファイル、探索loss
- `summary.json`: 選択フレーム、探索条件、最良 `G_b` / `chi` / 成長時間、Fréchet距離、
  曲率RMSE、baselineとの差、制約事項
- `candidate_scores.csv`: 粗探索・refine各候補の状態とスコア
- `best_fit_trajectory.npz`: 最良候補の全受理状態。`positions` と offset配列で
  remesh後の可変節点数にも対応する

`research_progress_presentation.py` は `summary.json` とPNGを読み込み、最良候補を
実中心線へ重ねた図、定量指標、censor状態、baselineからの相対改善を表示する。

## 物理的な読み方と限界

`G_b` が大きい候補で形状がよく重なる場合、成長と曲げ緩和の競合を表す無次元軸が
観察形状の記述に寄与する可能性はある。しかし、target代表フレームをseedにしているため、
これは予測的な動画再現ではなく、観察形状の周囲での探索である。この結果だけから
`G_b` や `chi` を物性値として同定できない。特に次の検証が必要である。

- pixel/model-unit と時間の独立校正
- censorを含むフレームを除いた holdout評価
- target初期形状・初期摂動を変えた感度分析
- 特徴量ベクトルの各成分を除外したアブレーションと、特徴量重みの感度分析
- 輪郭長、曲率、端点距離、接触時間など複数観測量の同時比較
- 実観察以外の合成データでのパラメータ回収テスト

したがって、図の「フィットできている」は、同じ座標スケールと向きで曲線の形状が
視覚的に重なるという意味に限定し、物理モデルの検証済み結論とは分けて扱う。
