# 検証計画

検証は、数値実装、力学モデル、実験比較、粗視化対応を分けて行う。下位の検証に合格していない結果を、上位の物理結論の根拠に使わない。

## Phase 0：実装の健全性

### 0.1 形状・幾何

- 直線の線分長、接線、二階差分が解析値と一致する。
- 平行移動でエネルギー・力が変わらない。
- 剛体回転でエネルギーが変わらない。
- ゼロ長線分は診断付きで拒否する。
- 非隣接線分の交差を検出する。
- 共有端点を持つ隣接線分を自己交差として誤検出しない。

### 0.2 エネルギー勾配

各エネルギー項について、解析的な力と有限差分勾配を比較する。

```text
F_i ≈ -[E(r_i + eps e) - E(r_i - eps e)] / (2 eps)
```

接触の閾値直上・直下は非滑らかなので、まず閾値から十分離れた状態で実施する。

受入条件は、`eps` の範囲で誤差が減少することとし、単一の誤差値だけで合格にしない。

### 0.3 成長・再メッシュ

- `growth_rate=0` で参照長が変化しない。
- 一様成長で `a(t)=a(0)exp(g t)` に一致する。
- 直線・折れ線の再メッシュ前後で、端点、総参照長、幾何学的輪郭長が丸め誤差内で一致する。
- 参照長が分割閾値以下になる。
- `radius_of_gyration` は従来どおり節点平均として保持する。
- 再メッシュ非依存の形状比較には `arc_length_weighted_radius_of_gyration` を使い、
  線形区間の弧長積分が保存されることを確認する。
- 曲げは局所参照長の接線差分離散化とする。固定角点の曲げエネルギー・節点力は
  曲率特異性のためメッシュ独立とはしない。滑らかな形状を各 `a_max` で弧長サンプルし、
  曲げエネルギー、弧長重み観測量、角点を除く内部力残差が定義した収束傾向を示す。
- 短い成長 run では、seedを要しない固定初期条件・固定パラメータから再メッシュ発生回数、
  節点数、保存量を再現できることを確認する。イベントログ自体は後続ゲートの対象とする。

## Phase 1：時間発展・散逸

### 1.1 成長なしの緩和

`growth_rate=0`、外力なし、接触なしで、曲がったフィラメントを緩和させる。
陽的Eulerの試行は、現在エネルギーに対する相対スケール
`energy_tolerance * max(1, |E_old|)` 以内でエネルギー非増加の場合だけ受理する。

既知の回帰条件は、4節点、初期座標
`[[0,0], [1,0.4], [2,0.4], [3,0]]`、参照長 `[1,1,1]`、`EA=100`、
`EI=1`、ドラッグ密度 `1`、両端固定、成長率 `0`、`a_max=2` である。
候補 `dt=0.01` の最初の陽的Euler試行はエネルギーを
`0.7364543328493227` から `1.1273023830776698` へ増加させるため棄却し、
状態と時刻を変更せず `dt=0.005` へ再試行する。失敗時は理由をエラーへ含める。

小規模診断では `dt=0.01` と `dt=0.005` をそれぞれ `t=0.05` まで実行し、
固定メッシュの全受理ステップについて、エネルギーと状態が有限であること、
エネルギー差が `1e-12 * max(1, |E_old|)` 以下であることを確認する。成長なしの
固定端緩和では、曲率の総量が減少し、`dt` を半分にすると軌跡差が減少することも確認する。

### 1.2 既知解・収束

再メッシュを発生させない3節点の製造解を使う。両端を固定し、節点を一直線上の
`[0, 1.25, 2]`、参照長 `[1,1]`、`EA=2`、`EI=1`、ドラッグ密度 `1`、成長率 `0`、
`a_max=2` とする。中央節点の厳密解は
`x(t)=1+0.25 exp(-4t)` であり、`t=0.2` の最終座標誤差を測る。

`dt=0.02, 0.01, 0.005`（それぞれ10、20、40ステップ）で実行し、`dt` 半減ごとの
観測次数が `0.9〜1.1` に入ること、全ケースの節点数が3で棄却ステップが0であることを
受入条件とする。この条件は空間再メッシュ誤差を含まない、陽的Eulerの時間誤差に対する
一次収束の検証である。

時間刻みを変えて結果が変わる場合、パラメータ掃引を始めない。

### 1.3 接触

- 排除径より離れた節点・線分には接触力が働かない。
- 排除径内では節点互換項と有限径線分 penalty 項がそれぞれ定式化どおり働く。
- 線分反発は最近接パラメータの形状関数で4端点へ散布され、作用反作用を満たす。
- 接触エネルギーの有限差分勾配と解析力が一致する。
- 剛体平行移動・回転で、線分接触エネルギー・力が不変／共変になる。
- 非隣接線分が交差する試行は棄却される。
- 接触を有効にした場合、交差・貫入の最大量を記録する。

最小 penalty prototype の定式化・境界条件・U字 fixture は
`notes/segment_penalty_contact.md` に記録する。大きな時間刻みでの非貫入は別途検証する。

### 1.4 Free/free 端点の力学的検証

実験との整合を目的とする主境界条件は `free/free` とする。`fixed/fixed` は従来の
固定端ベンチマークを壊していないことを確認するための control であり、実験境界の
根拠にはしない。端点では `F=-dE/dr` を natural force residual と定義し、離散曲げ
エネルギーの最初・最後の接線差分から bending-moment residual を、全端点力の外向き
法線成分から shear-equivalent residual を計算する。これらの規約は
`notes/free_end_dynamics.md` に記録する。

受入条件は次のとおりである。

- 無伸長直線・接触なしの free/free で、端点 force、moment、shear residual が丸め誤差内でゼロ。
- 平行移動で残差が不変、剛体回転で力ベクトルが共変し、残差ノルムと符号付き moment が保存。
- 成長なしの曲げ緩和で free/free の端点が移動し、エネルギーが非増加。fixed/fixed control の端点は不動。
- 3節点の一様成長で、最初の free-end 変位が成長後参照長を用いた離散伸長力の製造値に一致。
- `contact_stiffness=0` かつ `diameter=0` では、endpoint diagnostics に接触力・接触拘束がない。
- `benchmarks/free_end_benchmark.py` で、成長応答と曲げ緩和について free/free と fixed/fixed を
  時間・空間解像度別に実行し、端点時系列、work/dissipation、residual、refinement を compact に報告。
  このベンチマークから実験一致、座屈臨界値、有限径接触の結論は導かない。

全節点の長い軌跡はGitへ保存せず、ベンチマーク出力は `/tmp` 等へ compact summary のみを置く。

## Gate 3：有限径幾何・イベント・再現性

### 3.1 線分幾何

- 非隣接線分の最近接距離と最近接点を、交差しない平行・端点最近接・交差のfixtureで確認する。
- 有限径の `gap=d-D`、`penetration=max(0,D-d)`、径、最近接パラメータ、feature、normal statusを解析値で確認する。
- straight/no-contact、parallel、endpoint/interior、near-parallel、zero-distance、collinear overlap、閾値直上・直下をfixtureで確認する。
- `d=0` の中心線交差・重なりでは任意の法線を返さず、中心線交差と有限径 gap 接触を別診断として扱う。
- 剛体変換で距離・gap・penetration・パラメータを保存し、法線だけ回転することを確認する。
- 中点再メッシュ後も、現在の配列添字による非隣接pair除外で診断が有限かつ再現可能であることを確認する。添字はlineage IDではない。
- 初期交差はモデル生成時に拒否し、正常な初期形状は従来どおり生成・実行できることを確認する。
- 線分接触の幾何検出は力則から独立した診断レコードとして記録し、力の検証は
  `tests/test_segment_contact_forces.py` で行う。摩擦・接着・履歴は仮定しない。
- イベント状態要約から、最小線分長、最小非局所距離、有限性、最大移動量を追跡できることを確認する。

### 3.2 swept crossing

各試行の始終状態だけでなく、線形補間中の非局所線分交差を検査する。回帰fixtureは、
水平線分と移動する垂直線分が `t≈0.29` で交差し、`t=0` と `t=1` ではどちらも非交差となる。
このfixtureは swept crossing として棄却理由へ現れ、交差した状態が受理軌跡へ残らないことを確認する。

### 3.3 構造化イベント

各試行は要求 `dt`、試行 `dt`、受理 `dt`（棄却時はnull）、状態・エネルギー要約を持つイベントとして保存する。
少なくとも初期交差、接触、交差棄却、非有限値、移動量超過を別の理由として識別できることを確認する。
受理数・棄却数はイベント列とシミュレータの診断値で一致させる。

### 3.4 再現性

同じ初期状態・パラメータ・入力を2回実行し、イベント列、イベント列hash、canonical終状態hash、
Git revision、Python/NumPy、入力hash、初期状態hash、パラメータが一致することを確認する。
`save_trajectory()` のmanifest/event serializationはJSONとして再読込できることを確認する。
これは数値モデルの物理的妥当性や有限径接触の正しさを証明するものではなく、同一環境での再実行一致を検査する。

## Phase 2：力学的なベンチマーク

### 2.1 直線成長

両端固定の直線フィラメントを成長させる既存ベンチマークは、`free/free` 主モデルとの
比較用 control として扱う。実験境界条件の根拠にはしない。

測定対象：

- 軸方向圧縮力
- 参照長と現在長
- 成長率に対する応力
- 座屈開始時刻

成長が遅い極限では準静的な弾性応答に近づき、成長が速いほど散逸に遅れが生じることを確認する。

### 2.2 座屈

初期ゆらぎを複数の大きさで与え、次を測る。

- 座屈の有無
- 座屈開始条件
- 最大曲率
- 座屈波長
- 成長率・曲げ剛性・境界条件への依存

初期ゆらぎを変えて座屈開始条件が大きく変わる場合、線形安定性と非線形発展を分けて解析する。

### 2.3 接触・折りたたみ

U字またはS字の初期形状を用いて、接触後の挙動を調べる。

- 接触したまま成長するか
- 反発して離れるか
- 交差せずに折りたたまれるか
- 接着を追加した場合に形態がどう変わるか

実験で接触したひもが滑らずに成長するなら、反発だけの接触則では不十分である可能性が高い。

## Phase 3：実験データとの整合

### 3.1 データ契約

実験データは、少なくとも次の形式を目標にする。

```text
time, filament_id, point_id, x, y, quality
```

付随するmetadata：

- 画像ファイルID
- ピクセルから物理長への換算
- 撮影間隔
- 温度、栄養条件、寒天条件
- セグメンテーション方法
- 欠損・視野外の扱い

### 3.2 校正と予測の分離

校正用データと評価用データを分ける。

校正候補：

- 全長の時間発展から成長率
- 単純な曲げ緩和から `EI/zeta`
- 伸長応答から `EA`
- 接触挙動から径・接触パラメータ

評価候補：

- 曲率分布
- 折りたたみ間隔
- 接触長
- 端点間距離
- 慣性半径
- roughness
- フラクタル指標の時間発展

同じ観測量を校正と評価の両方に使わない。

### 3.3 適合の評価

画像の見た目だけでなく、以下を比較する。

- 時系列の平均と分布
- replicate間のばらつき
- 時間相関
- 曲率の確率分布
- 接触時間分布
- 成長率の条件依存性

「見た目が似ている」だけでは実験整合と判定しない。

## Phase 4：三角格子粗視化との比較

同一の物理量を、連続モデルと三角格子モデルから計算する。

| 量 | 連続モデル | 三角格子モデル |
|---|---|---|
| 長さ | 輪郭長 | ステップ数×格子間隔 |
| 剛直性 | `EI` | `beta`の曲げバイアス |
| 形状 | 中心線座標 | 6方向ベクトル列 |
| 接触 | 距離・接触長 | 占有・近傍関係 |
| 時間 | 物理時間 | 成長ステップまたは較正時間 |

比較する前に、以下を固定する。

- 境界条件
- 初期形状
- 代表長
- 成長量
- replicate数
- 観測量の定義

`beta` を物理温度や曲げ剛性とみなす前に、接線相関または実効持続長による較正を行う。対応が一意でなければ、`beta` は粗視化パラメータとして残す。

## Phase 5：統計解析

- 乱数seedとreplicateを保存する。
- 時系列フレームを独立サンプルとして扱わない。
- replicate単位で平均、分散、信頼区間を計算する。
- 格子サイズ、フィラメント長、成長ステップを変える。
- 単一クラスター固有の結果と、複数クラスターの平均を分ける。
- フィット区間、除外規則、モデル式を保存する。

KPZなどの普遍性を検討する場合は、単一のroughnessまたはフラクタル次元ではなく、系サイズ・時間を変えた動的スケーリングを確認する。

### Gate 2 の実行コマンド

```bash
PYTHONPATH=continuum_filament_model/src \
python -m unittest discover -s continuum_filament_model/tests -v

PYTHONPATH=continuum_filament_model/src \
python continuum_filament_model/benchmarks/time_integration.py
```

前者が既存テストを含む回帰スイート、後者が製造解の収束値と固定メッシュ診断の
エネルギー時系列・受理/棄却 `dt`・棄却理由を出力する。成長ありの試行では、成長が
エネルギーを注入し得るため、単調減少を受入条件にしない。

## 検証を通過するまでの禁止事項

- 実験データへフィットする前に複数の自由パラメータを追加する。
- seed・環境・コードrevisionを保存しない実験を確定結果として扱う。
- 再メッシュ依存性を確認せずに曲率分布を解釈する。
- 周期境界の距離定義を確認せず、既存の格子結果と比較する。
- 既存のlegacy結果を、生成条件が確定したデータとして扱う。
- 単一画像からKPZ、WLC、アクティブマターなどへの帰属を行う。
