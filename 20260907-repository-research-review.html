5. レビュー時に注意する点

最重要の注意：現状のファイル構成やコードから、実行環境・再現性・結果の科学的妥当性を断定しない。

  • ルートREADMEの python proto.py は、ルート直下の現状の配置と一致しない。
  • READMEの img/screen_001.png に対し、確認できる同名ファイルは img/screen_001.pdf。
  • Python 2系の構文・APIとPython 3向けの記述が混在する。
  • 依存関係マニフェスト、標準テスト、lint、CI設定は確認できない。
  • 結果出力は相対パスが多く、実行する場所によって入力・出力先が変わり得る。
  • 内部領域判定の技術メモには、i=0 をまたぐ場合の既知の問題が記載されている。
